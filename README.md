# UART

This is an implementation of the Universal Asynchronous Transmitter Receiver serial communication protocol in Verilog.

UART uses two wires, tx and rx, to serially communicate data between the transmitter and receiver.
The baud rate of UART is the rate of data transfer in bits/second.

This implementation is a 19200 bits/second baud rate, 1 stop bit and 0 parity bit implementation.

The transmiiter serially shifts out the tx_in data over the tx line which is received by the receiver.
An oversampling scheme is used to sample the bit at the middle point of transmission for least probability of error.
This oversampling is accomplished by using a baud_tick driven transmission and reception, which is generated by the baud_generator.

Every 16th baud_tick, one bit is shifted out by the tx. The rx samples the bit on all ticks, and takes the value of rx at the middle tick to be stored.
